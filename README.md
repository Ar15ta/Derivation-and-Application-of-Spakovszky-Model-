Spakovszky Model for Compressor Stability: Derivation, Code, and Application

Derivation: Full mathematical reconstruction of the Spakovszky stability model (PhD thesis), with annotated steps and physical interpretations.

Input: Mean-line flow data or EXP data, or CFD data.

Output: Estimated stall/surge boundary、 stability map and more information relative to linear perturbation theory.

Scope: Applicable to general compressor configurations with moderate loss characteristic gradients.

Code: Python implementation with example cases.
